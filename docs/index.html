BAB 1: Gambaran Umum & Arsitektur Sistem

CBT Nova adalah aplikasi ujian terdistribusi berbasis web yang dibangun dengan orientasi performa ekstrem (*zero-latency execution*), keamanan anti-cheat multi-lapis, dan antarmuka responsif ramah gawai.

Spesifikasi Teknologi

Komponen Teknologi Terpasang Fungsi / Keunggulan
Backend Core PHP 8.1+ / 8.2 (Strict Types & Native PDO) Eksekusi cepat, hemat memori, dan zero external overhead.
Database Engine MySQL 8.0+ (InnoDB + Composite Covering Indexes) Optimasi query sub-10ms pada tabel ratusan ribu baris.
Frontend UI Tailwind CSS + Vanilla JavaScript (ES6+) Render instan tanpa jeda framework (React/Vue load overhead).
Web Server Nginx 1.24+ Reverse Proxy & PHP-FPM Menangani ribuan koneksi konkuren (*keep-alive pooling*).

BAB 2: Panduan Instalasi & Deployment Step-by-Step

Petunjuk resmi instalasi pada lingkungan pengembangan lokal dan server produksi Linux Ubuntu/Debian.

1

Install Dependensi Server

Jalankan apt install php8.2-fpm php8.2-mysql php8.2-gd php8.2-fileinfo pada terminal SSH server.

2

Clone Repositori

Tarik source code terbaru dari GitHub menggunakan git pull origin main.

3

Konfigurasi Database

Salin config/database_prod.php ke config/database.php dan sesuaikan user/pass.

4

Migrasi Skema SQL

Import skema idempotent sql/sync_production_schema.sql ke database MySQL server.

Skrip Eksekusi Cepat di Terminal Linux:

# 1. Update kode & migrasi database
cd /var/www/cbt_nova
git pull origin main
mysql -u user_cbt -p cbt_nova_v2 < sql/sync_production_schema.sql

# 2. Atur perizinan file
sudo chown -R www-data:www-data /var/www/cbt_nova
sudo chmod -R 755 /var/www/cbt_nova
sudo chmod -R 775 /var/www/cbt_nova/assets/uploads

# 3. Restart engine
sudo systemctl restart php8.2-fpm nginx

BAB 3: Skema Basis Data & Strategi Indeks

Sistem didukung oleh 26 tabel relasional yang dirancang dengan skema normalisasi tinggi dan indeks penutup (*covering index*):

  • cbt_students: Data siswa aktif dan alumni (didukung kolom status enum dan foto).
  • cbt_device_locks: Mengunci 1 akun siswa pada 1 gawai spesifik secara otomatis.
  • cbt_cheat_logs: Mencatat pelanggaran anti-cheat (tab switch, screenshot, shortcut).
  • cbt_display_tokens: Menyimpan token tayangan proyektor publik terenkripsi.
  • cbt_exam_participants: Rekaman sesi ujian realtime terindeks (exam_id, status).

BAB 4: Konfigurasi Lingkungan (Environment Parity)

Aturan Ketat Case-Sensitivity Linux:

Seluruh path include diwajibkan menggunakan huruf kecil dan fungsi dirname(__DIR__, n) untuk mencegah HTTP 500 akibat perbedaan sistem file Windows vs Linux.

BAB 5: Panduan Penggunaan Panel Admin

1. Manajemen Master Siswa & Fitur Alumni

Admin dapat memfilter siswa berdasarkan status Aktif dan Alumni. Siswa yang diluluskan dapat dikembalikan (restore) statusnya kapan saja dengan menekan tombol "Kembalikan ke Aktif".

2. Monitoring Proktor & Kontrol Realtime

Menampilkan status langsung seluruh siswa: working, finished, blocked. Proktor dapat melakukan aksi seketika:

  • Reset Login: Melepas kunci perangkat siswa jika gawai rusak.
  • Buka Blokir: Mengizinkan siswa yang melanggar anti-cheat 3x untuk melanjutkan tes.
  • Tambah Waktu: Menambah durasi peserta (+15/+30 menit).
  • Selesaikan Paksa: Menutup ujian peserta secara sepihak.

BAB 6: Panduan Penggunaan Panel Guru

Panel guru dilengkapi fitur bank soal terpadu 4 jenis (PG Tunggal, PG Kompleks, Menjodohkan, Esai) dengan sistem keamanan Teacher Scoping (guru hanya dapat memonitor ujian yang dibuatnya sendiri).

BAB 7: Engine Ujian Siswa & Anti-Cheat

Mesin ujian siswa mengusung standar pengamanan ujian internasional:

  • Auto-Save Anti-Hilang: Setiap kali opsi dipilih, jawaban langsung terkirim via background AJAX dengan proteksi cache lokal.
  • Deteksi Blur & Pindah Tab: Kehilangan fokus jendela browser langsung memicu peringatan. Pada pelanggaran ke-3, ujian terkunci otomatis.
  • Blokir Shortcut: Mencegah tombol F12, Ctrl+U, PrintScreen, Alt+Tab, dan klik kanan.

BAB 8: Modul Display Publik & Live Scoreboard

Layar proyektor menampilkan klasemen nilai ujian secara realtime tanpa perlu login (menggunakan token hash aman). Fitur Masking Nama menyamarkan nama siswa demi privasi.

BAB 9: Standar Operasional Prosedur (SOP) Ujian

Fase Aksi Administrator / Proktor Aksi Guru
Pra-Ujian (H-1) Verifikasi akun siswa, backup database, rilis jadwal ujian. Cek kunci jawaban & validasi butir soal.
Hari H Ujian Buka monitoring proktor, tangani reset device lock jika gawai siswa rusak. Membantu pengawasan ruang ujian.
Pasca-Ujian Force finish peserta yang belum selesai, export nilai Excel/PDF. Koreksi nilai esai manual.

BAB 10: Panduan Troubleshooting (Pemecahan Masalah)

Penyebab & Solusi Masalah Lapangan Terpopuler:

  1. HTTP 500 di Server Linux: Jalankan migrasi sql/sync_production_schema.sql di database server.
  2. Siswa "Perangkat Terkunci": Masuk ke Admin $\rightarrow$ Monitoring $\rightarrow$ Device Lock $\rightarrow$ Klik Reset Login.
  3. Gagal Upload Gambar: Pastikan ekstensi php-fileinfo dan php-gd aktif di PHP server.

BAB 11: Standar Keamanan Sistem & AppSec

Sistem telah melalui audit kepatuhan keamanan ketat:

  • 100% Prepared Statements: Mencegah seluruh celah SQL Injection.
  • CSRF Token Verification: Memvalidasi seluruh mutasi data POST/AJAX.
  • Magic Bytes Upload Check: Memastikan file yang diunggah adalah gambar murni bukan script berbahaya (.php tersembunyi).
