B. Rincian Remediasi Teknis 16 Critical & 511 High

Validasi Magic Bytes MIME
Menerapkan finfo_file(FILEINFO_MIME_TYPE) dan validasi biner pada modul impor Excel, Word, TinyMCE, dan foto siswa. Menolak mutlak ekstensi manipulasi (CWE-434).
Global Context-Aware Escaping
Mengamankan 671 titik atribut HTML (data-*, href, value) dengan helper e() / htmlspecialchars() untuk menutup Attribute-Break XSS.
Isolasi Payload Data JSON
Mengganti atribut onclick="edit('json')" dengan tag <script type="application/json"> yang di-parse via JavaScript murni, mencegah injeksi kode berbahaya.
Isolasi Kunci Jawaban
Kolom cbt_question_options.is_correct tidak pernah dimuat ke memori PHP saat siswa meminta soal. Kunci jawaban tidak dapat diintip dari Inspect Element / Network Tab.
