- Backend: PHP 8.x (Native)
- Database: MySQL / MariaDB (PDO Driver)
- Frontend: Bootstrap 5, FontAwesome 6, Inter Font Family
- Library: jQuery 3.6, SweetAlert2 (untuk notifikasi interaktif)

Cara Instalasi
1. Clone repositori ini.
2. Import file database (SQL) ke phpMyAdmin Anda.
3. Sesuaikan konfigurasi database di /config/database.php.
4. Jalankan pada server lokal (XAMPP/Laragon/flyenv).
